# ЭТРА — премиальный сайт бренда живых ферментов

Статический сайт по ТЗ («Сайт ТЗ.pdf») и сайтмэпу (XMind «ЭТРА сайт», версия после встречи 27 мая).

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная — один плотный скролл: hero, манифест, «Зачем вы тут?» (раскрывающиеся плашки Энзимы/Бактерии/Технология/Результат), «С чего начать» (Чистим·Наполняем·Закрепляем), горизонтальная лента каталога, хиты, контрасты до/после, бары результатов, отзывы, Кирилл, МПК «Открыть производство вместе», команда, партнёры, база знаний, FAQ + CTA |
| `catalog.html` | Каталог с сегментацией по ТЗ: Все напитки · Комплексные решения · Энзимные коктейли · Сезонные · Питание и чистки · Съедобная косметика · Для фанатов + inline-квиз |
| `product.html?id=…` | Карточка товара: галерея, состояние («Я в ресурсе» и т.п.), состав, эстетика производства (ферментировано Х часов · 10 атм · без термообработки), эстетика вкуса, применение и противопоказания, результаты по неделям, cross-sell |
| `start.html` | Квиз «С чего начать» — 5 вопросов, подбор продукта, флаги осторожности (лекарства/беременность) |

## Технологии

- Ванильные HTML/CSS/JS, без сборки — открывается с любого хостинга/cPanel.
- GSAP + ScrollTrigger + Lenis (вендорятся локально в `assets/vendor/`).
- Шрифты Cormorant Garamond + Manrope (кириллица), self-hosted в `assets/fonts/`.
- Изображения сгенерированы gpt-image-2 по референсу заказчика, оптимизированы в WebP (`assets/img/`).
- Корзина — мок на localStorage; checkout по сайтмэпу остаётся существующим (Юкасса/СДЭК не трогаем).

## Скролл-эффекты

Прелоадер с логотипом, smooth-scroll (Lenis), параллакс изображений, line-mask reveal заголовков, посветочная анимация манифеста по словам, pinned горизонтальная лента категорий, дрейф ленты отзывов, анимированные бары результатов и счётчики, смена темы фона (крем ↔ лес) по секциям, кастомный курсор, magnetic-ховеры кнопок, зерно-оверлей, канвас-пузырьки живой ферментации в hero.

## Запуск

```bash
cd website && python3 -m http.server 8080
# открыть http://localhost:8080
```
